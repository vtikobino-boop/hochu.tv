# hochu.tv private web app

هذا مشروع PWA بسيط يمكن نشره على GitHub Pages ثم إضافته إلى الشاشة الرئيسية للهاتف.

## التشغيل
1. ارفع الملفات إلى مستودع GitHub.
2. فعّل GitHub Pages من Settings → Pages.
3. اختر Branch: `main` والمجلد: `/ (root)`.
4. افتح رابط Pages على الهاتف.
5. من المتصفح اختر إضافة إلى الشاشة الرئيسية، أو استخدم زر تثبيت إذا ظهر.

المشروع لا ينسخ محتوى الموقع ولا يتجاوز حماياته؛ زر "فتح الموقع" يفتح `https://hochu.tv/`.
